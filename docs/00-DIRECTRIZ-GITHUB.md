# DIRECTRIZ OBLIGATORIA — GITHUB COMO ÚNICA FUENTE DE VERDAD

**El repositorio GitHub [JavierRB35/Scriptura-web](https://github.com/JavierRB35/Scriptura-web), rama principal `main`, constituye la ÚNICA FUENTE DE VERDAD del proyecto Scriptura Web.**

Esta directriz es obligatoria para cualquier desarrollador, agente de IA o herramienta que intervenga en el proyecto.

1. **Lectura obligatoria:** antes de iniciar cualquier trabajo, consultar el repositorio para conocer el estado real del proyecto, su código, documentación, decisiones vigentes y funcionalidades implementadas.

2. **Escritura obligatoria:** toda modificación del código, documentación, configuración versionable, especificaciones, decisiones técnicas o pruebas deberá incorporarse al mismo repositorio mediante commits trazables.

3. **Sin fuentes paralelas:** queda prohibido mantener repositorios alternativos, documentación externa o copias locales como fuentes de verdad independientes. Las copias de trabajo serán exclusivamente temporales y deberán sincronizarse con GitHub.

4. **Continuidad entre sesiones:** cualquier desarrollador o agente que retome el proyecto deberá poder conocer su estado, avances, decisiones y tareas pendientes consultando exclusivamente el repositorio, sin depender del historial de conversaciones anteriores.

5. **Trazabilidad:** las decisiones relevantes, cambios realizados, incidencias y resultados de pruebas deberán quedar registrados en GitHub de forma clara, concisa y verificable.

6. **Prioridad documental:** ante cualquier contradicción, prevalecerán las instrucciones vigentes y aprobadas del repositorio frente a documentos antiguos, conversaciones anteriores o información no sincronizada.

7. **Agilidad:** trabajar preferentemente sobre `main` para modificaciones menores y seguras, respetando las protecciones existentes. Utilizar ramas y pull requests únicamente cuando estén justificados por la complejidad, el riesgo o las reglas del repositorio.

**Excepción técnica:** los datos operativos de usuarios, comentarios y demás información dinámica persistirán en la base de datos definida para Scriptura. Las credenciales y secretos permanecerán en sistemas seguros, nunca en GitHub. El repositorio conservará sus esquemas, migraciones, configuraciones versionables y documentación.

## PRINCIPIO IRRENUNCIABLE

**Todo trabajo comienza leyendo GitHub y termina actualizando GitHub.**

Ningún avance podrá considerarse definitivamente incorporado al proyecto mientras no esté integrado, versionado y verificable en `JavierRB35/Scriptura-web`.

**GitHub es el punto único de entrada, salida, continuidad y trazabilidad de todo el desarrollo de Scriptura Web.**
